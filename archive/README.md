# Archive

Reference-only files. Nothing here is deployed by chezmoi or the install
scripts.

- `desktops/sway`, `desktops/i3` — X11/wlroots desktop configurations.
- `tools/rofi` — launcher configuration.
- `shell/zsh4humans`, `shell/xonsh` — shell framework configurations.
- `shell/fish` — `bass`/`foreign-env` helper configuration.
- `editors/lvim` — LunarVim configuration.
- `bin` — scripts for i3/sway/rofi/polybar/ntpd and external tools.
- `system/dracut.conf.d` — dracut configuration.
- `system/zram-generator.conf` — zram configuration example.
- `docs` — browser, desktop, and setup notes.
- `install/installation.txt` — scratch installation notes.
- `Plain_jane` — helper script; uses `loginctl`, DMS, `mpv`, and `pamixer`.
