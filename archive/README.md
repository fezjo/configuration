# Archive

Kept for reference only. Nothing here is deployed by chezmoi or by the install
scripts.

Moved out of the active configuration when the setup moved to niri + DMS:

- `desktops/sway`, `desktops/i3` — old X11/wlroots desktop configurations.
- `tools/rofi` — launcher configuration; DMS owns the launcher now.
- `shell/zsh4humans`, `shell/xonsh` — unused shell frameworks/configuration.
- `shell/fish` — `bass`/`foreign-env` helpers replaced by the environment loader.
- `editors/lvim` — LunarVim configuration; Neovim/Helix are the current editors.
- `bin` — scripts tied to i3/sway/rofi/polybar/ntpd or broken external tools,
  including the old `I3exit` and `Blurlock` helpers.
- `system/dracut.conf.d` — superseded by mkinitcpio on this system.
- `system/zram-generator.conf` — owned and generated by `4-memory.sh`.
- `docs` — obsolete browser/setup notes.
- `install/installation.txt` — old scratch installation notes.

`Plain_jane` remains active, but it now uses `loginctl`/DMS and `mpv`/`pamixer`
instead of `I3exit`, `i3lock`, `sox`, and `Pulseaudio-ctl`.
